# Learning Pack — API Documentation

- **Source of truth:** the OpenAPI schema generated by drf-spectacular. Run `/api/schema/` (YAML) or `/api/docs/` (Swagger UI) on a running backend, or `venv/bin/python3 manage.py spectacular --file schema.yml`.
- This file covers conventions and the inventory. It doesn't duplicate the schema.

## Conventions
- **Base:** `/api/v1/` (preferred). `/api/` is the legacy alias serving the same routes and will be deprecated once the web, Next.js and Flutter clients migrate.
- **Auth:**
  - `POST /api/v1/auth/login/` returns `{access, refresh}`.
  - Students use `POST /api/v1/auth/student-login/`.
  - `POST /api/v1/token/refresh/` refreshes. Send `Authorization: Bearer <access>`.
- **Tenancy:** derived from the authenticated user's school. Clients must not send `school` on create; the server sets it. *(Currently not enforced everywhere, see SECURITY C4/M5.)*
- **Pagination / filtering:** DRF + django-filter (`filterset_fields` per ViewSet).
- **Public (no auth) endpoints:** product catalogue, discovery, storefront, booklists academic years, recruitment application, form submissions, guest orders, payment webhook. All of them need throttling (SECURITY H6).

## Known schema issues
- `website.PublicWebsiteView` and `transport.DriverStudentsView` have no serializer, so they're missing from the schema.
- dj-rest-auth registration views error out (custom User has no `username`).

## Changes log

### 2026-11-12 — critical security fixes (backend `02512d7`)
| Endpoint | Change |
|---|---|
| `POST /shop/orders/{id}/pay_mpesa/` | Now Daraja STK push. Body `{phone}`. Returns `{detail, checkout_request_id, payment_status}`. Retrying after a failure reuses the payment record. |
| `GET /shop/orders/{id}/payment-status/` | **New.** Returns `{order_status, payment_status, result_desc, mpesa_receipt_number}`. Re-checks Daraja server-side (at most every 10s). |

| `POST /shop/payments/mpesa/callback/{secret}/` | **New** Daraja callback (configure `MPESA_CALLBACK_URL` + `MPESA_CALLBACK_SECRET`). Not for clients. |
| `POST /shop/webhooks/chama/` | **Retired:** 410 Gone |
| `POST /auth/change-password/` | **New.** `{current_password, new_password}` |

| `POST /auth/users/bulk_import/` | Response adds `temporary_password` per created row and `new_parent_credentials` (shown once) |
| `POST /auth/student-login/` | Optional `school_code`. Same admission number in two schools no longer crashes. |
